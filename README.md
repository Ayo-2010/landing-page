# Pulse

A product landing page for a fictional team workspace.

## Features

- Animated hero with a dashboard preview mockup
- Scroll-reveal sections and live counters
- Monthly / yearly pricing toggle with animated numbers
- FAQ accordion and a validated sign-up form

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour
```

## Tech

Plain HTML, CSS and JavaScript.
